### task07.py — верхний и нижний треугольник матрицы

**Задача:** есть квадратная матрица. Нужно сделать два списка (одномерных массива).

**Как решено простыми словами:**

1. Пользователь вводит размер матрицы `n` и саму матрицу построчно.
2. Программа идёт по матрице **строка за строкой**.
3. **Верхний треугольник** — это элементы на главной диагонали и выше неё (справа от диагонали).  
   Для строки `i` берём столбцы, где номер столбца `j` не меньше номера строки (`j >= i`).
4. **Нижний треугольник** — это элементы на главной диагонали и ниже неё (слева от диагонали).  
   Для строки `i` берём столбцы, где `j <= i`.
5. Оба списка выводятся на экран.

**Пример** для матрицы 3×3:

```
1 2 3
4 5 6
7 8 9
```

- Верхний треугольник: `[1, 2, 3, 5, 6, 9]`
- Нижний треугольник: `[1, 4, 5, 7, 8, 9]`

### task21.py — умножение строк первой матрицы на максимум второй

**Задача:** есть две квадратные матрицы A и B. Нужно получить новую матрицу C.

**Как решено простыми словами:**

1. Пользователь вводит размер `n` и обе матрицы.
2. Для **каждой строки** матрицы B находим **самое большое число** в этой строке.
3. Все элементы **той же строки** матрицы A умножаем на этот максимум.
4. Так получается строка новой матрицы C.
5. В конце печатаем A, B и готовую C.

**Пример:**

```
A = [[1, 2],     B = [[5, 6],
     [3, 4]]          [7, 8]]

В строке 1 матрицы B максимум = 6  →  1*6=6,  2*6=12
В строке 2 матрицы B максимум = 8  →  3*8=24, 4*8=32

C = [[6, 12],
     [24, 32]]
```
